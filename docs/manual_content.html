RAPTOR DEFENSE v2.0 // Manuel de Référence (Mode CLI)


NOM

rap - Arsenal souverain d'audit défensif, traque mémoire et neutralisation d'urgence.


SYNOPSIS

rap [options] [arguments]

rap [drapeaux_globaux]


DESCRIPTION

RAPTOR DEFENSE v2.0 est un bouclier d'investigation système et d'intervention en espace utilisateur C99 strict. Conçu selon les principes de l'ingénierie critique (zéro allocation dynamique sur le tas, exécution bornée sur la pile, zéro dépendance externe), il opère directement sur les structures natives du noyau Linux (/proc, fanotify, netlink).


---


COMMANDES DISPONIBLES


status (alias: st)

Bilan vital instantané de la machine hôte.

* Syntaxe : rap status

* Description : Scanne l'état global du système, la charge mémoire vive, l'intégrité de la table des processus et signale tout indice de compromission immédiat.


top

Top des consommateurs de mémoire vive résidente.

* Syntaxe : rap top [-n limite]

* Description : Analyse /proc/[pid]/status et trie les processus par empreinte VmRSS décroissante sans recourir à des forks externes.


hunt

Audit combiné complet multi-vecteurs.

* Syntaxe : rap hunt

* Description : Exécute en une seule passe séquentielle la traque des pages mutées (rx), les détournements d'environnement (preload) et les anomalies d'exécution (heur).


rx

Traque des mutations de pages exécutables anonymes (Inode 0).

* Syntaxe : rap rx

* Description : Inspecte /proc/[pid]/maps pour détecter les injections de code dynamique, coquilles de décompression (*packers*) ou segments rwx / r-x sans ancrage fichier sur le disque.


preload

Traque des détournements d'édition de liens dynamique.

* Syntaxe : rap preload

* Description : Audit /etc/ld.so.preload et les environnements mémoire /proc/[pid]/environ pour repérer toute usurpation de symboles partagés (rootkits en espace utilisateur).


heur (alias: he)

Analyse heuristique des comportements furtifs.

* Syntaxe : rap heur

* Description : Détecte les binaires supprimés toujours actifs ((deleted)), les exécutions depuis des répertoires temporaires volatils (/tmp, /dev/shm) et les usurpations d'identité noyau.


net

Audit des communications réseau TCP établies.

* Syntaxe : rap net

* Description : Analyse /proc/net/tcp et /proc/net/tcp6 pour corréler chaque socket active avec son PID réel et sa ligne de commande associée.


sentry (alias: se)

Sentinelle passive anti-rançongiciel (canaris & fanotify).

* Syntaxe : rap sentry [chemins...]

* Sous-commandes :

* arm [chemins...] : Déploie des fichiers leurres denses (!00_raptor_vault.kdbx, 32 Ko, signature KeePass KDBX4 authentique). Cibles par défaut : /home, /var/www, /var/lib, /etc.

* disarm [chemins...] : Supprime proprement les leurres lors des opérations de maintenance.

* status : Contrôle la présence et la taille exacte des canaris armés.

* run [-d] [chemins...] : Active la veille passive noyau FAN_OPEN_PERM (0% CPU au repos). Le drapeau -d active le détachement en arrière-plan, le masquage prctl ([kworker/u16:3]), le verrouillage mlockall et l'immunité mémoire /proc/self/oom_score_adj = -1000.

* Réaction cinétique : Gel conservatoire immédiat (SIGSTOP, état T) et rejet synchrone de l'ouverture (FAN_DENY) dès qu'un processus tente d'accéder à un leurre.


kill

Neutralisation chirurgicale immédiate par signal SIGKILL.

* Syntaxe : rap kill

* Description : Vérifie les gardes-fous anti-suicide système (PID <= 1, processus père) et applique un signal SIGKILL direct sans délai.


freeze

Suspension conservatoire d'un processus suspect pour analyse.

* Syntaxe : rap freeze

* Description : Envoie le signal SIGSTOP pour figer l'état du suspect sans détruire sa mémoire vive (permet l'extraction forensique de clés de chiffrement en RAM).


man

Affiche ce manuel de référence autonome embarqué.

* Syntaxe : rap man

DRAPEAUX GLOBAUX

* -q, --quiet : Mode silencieux (supprime bannières et en-têtes ANSI).

* -r, --raw : Sortie brute délimitée par tabulations pour scripts shell et pipelines.

* -f, --force : Ignore les invites de confirmation interactive.

* -v, --verbose : Affiche les métriques détaillées d'audit.

* -h, --help : Affiche l'aide abrégée et quitte.

* -n : Limite le nombre de lignes retournées (ex: rap top -n 5).


CODES DE RETOUR POSIX

* 0 : Exécution nominale, aucun élément hostile détecté.

* 1 : Alerte sécurité levée (anomalie détectée ou processus intercepté).

* 2 : Erreur d'exécution, argument invalide ou privilèges insuffisants (root requis).


DROITS SYSTÈME REQUIS

L'interception au niveau du noyau (sentry) et l'envoi de signaux inter-processus (kill, freeze) exigent les privilèges administrateur (root) ou l'attribution des capacités POSIX suivantes :

setcap 'cap_sys_admin,cap_kill,cap_ipc_lock=+ep' /usr/local/bin/rap
