Architecture & Outils de Combat

Une batterie de sondes indépendantes interrogeant directement l'arborescence /proc sans dépendance logicielle lourde.

RX

Traque Mémoire Inode 0

Inspecte chirurgicalement /proc/[PID]/maps pour débusquer les pages exécutables clandestines (r-xp) orphelines de fichier disque. Filtre passivement les compilateurs JIT légitimes et trampolines libffi via mem_whitelist.conf.

COMMANDE : rap rx [-v]
NET

Net-Guard & Net-Intel

Analyse passive des sockets sous /proc/net/tcp. Évaluation mathématique CIDR (/8 à /32) et confrontation instantanée aux flux OSINT (C2, botnets, proxies) sans aucune fuite réseau externe.

COMMANDES : rap net | rap net -i <IP>
PL

Chasseur LD_PRELOAD

Traque les rootkits userland furtifs par une inspection à double palier : contrôle d'intégrité de la persistance globale sous /etc/ld.so.preload et audit des variables d'environnement actives dans /proc/[PID]/environ.

COMMANDE : rap preload
HR

Analyseur Heuristique

Détecte les binaires supprimés du disque en cours d'exécution (deleted), les lancements suspects depuis des répertoires volatils (/tmp, /dev/shm) et l'usurpation de démons système critiques (Masquerading).

COMMANDE : rap heur
0H

Téléscripteur rapless

Pager autonome d'urgence opérant strictement en 0 heap (zéro allocation dynamique). Capable d'indexer et naviguer dans des dizaines de milliers de lignes du noyau (/proc/kallsyms) en cas d'effondrement du terminal ou du serveur X11/Wayland.

UTILITAIRE : rapless
PID

Riposte Cinétique Protégée

Neutralisation chirurgicale immédiate (SIGKILL) ou gel conservatoire forensique (SIGSTOP en état T). Verrous stricts interdisant tout tir sur le PID 1, sur soi-même, sur le shell parent ou sur les threads du noyau.

COMMANDES : rap kill | freeze

Déploiement & Compilation

Aucune dépendance externe requise pour la trousse CLI de secours. Norme C99 stricte.

bash — Terminal de compilation
# 1. Rapatrier le dépôt source git clone https://github.com/BINOKUB-GAME/RAPTOR.git cd RAPTOR # 2. Configurer et compiler avec optimisations de combat (-O3) cmake -B build -DCMAKE_BUILD_TYPE=Release cmake --build build # 3. Lancer l'audit de sécurité universel combiné ./build/rap hunt # 4. Naviguer dans les flux massifs avec le téléscripteur 0 heap ./build/rap hunt | ./build/rapless
